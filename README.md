# VoxGlobal Pro - Manual Técnico

### 🚀 Características
- **Grid 2x2:** Diseño de cuadrícula optimizado para el Hub.
- **Trazabilidad:** Registro automático de fecha de creación y última edición.
- **Selección Total:** Editor diseñado para que el título y el cuerpo se seleccionen juntos.
- **Respaldo Híbrido:** Usa el botón "Maletín de Seguridad" para exportar tus datos a JSON.

### 🔑 Seguridad (Fabián)
- **Modo Dios:** Mantén presionado "VOXGLOBAL PRO" por 7 segundos.
- **PIN:** Inicia en `1010`. Puedes cambiarlo dentro del menú secreto.
- **Borrado Múltiple:** Actívalo desde el menú lateral para gestionar tus guiones en bloque.

### 🎤 Producción
- El sistema de audio (Oír) leerá lo que tengas seleccionado. Si no seleccionas nada, leerá el documento completo.
